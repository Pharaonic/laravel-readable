# Code of Conduct

## Our standards

Be respectful, constructive, and focused on the technical work. Harassment, discrimination, personal attacks, and intentionally disruptive behavior are not acceptable.

## Scope

This code of conduct applies to repository discussions, issues, pull requests, reviews, and other project spaces maintained by Pharaonic.

## Enforcement

Project maintainers may edit, remove, or reject contributions and participation that violate these standards.
